# 🔌 Remo — かんたん SSH クライアント

Windows 11 専用の、シンプルで見た目のきれいな SSH クライアントです。
**exe ファイル 1 つだけで動作**し、インストールや追加のライブラリ(DLL)は必要ありません。
RLogin のような使い心地を目指しつつ、機能を絞って迷わず使えるようにしています。

---

## ✨ 主な機能

| | 機能 | 内容 |
|---|---|---|
| 🖱️ | ワンクリック接続 | 登録した接続先のカードをクリックするだけで接続・切断 |
| 🔐 | 接続情報の暗号化保存 | サイト名・接続先・ユーザー名・パスワードを Windows の DPAPI で暗号化して保存(マスターパスワード不要) |
| 🎨 | カラー表示 | 256 色/TrueColor 対応。htop・vim・less などの全画面アプリもそのまま表示 |
| 😀 | カラー絵文字 | DirectWrite でカラー絵文字を描画 |
| 📋 | 右クリックでコピー&ペースト | 文字を選択して右クリック=コピー、選択なしで右クリック=ペースト(AI とのやり取りに便利) |
| 📐 | ウィンドウサイズの記憶 | 表示メニューで現在のサイズを記憶し、端末画面のトリプルクリックでそのサイズに戻す |
| 🔤 | 文字コード | UTF-8 / シフトJIS(接続先ごとに設定) |
| 🅰️ | フォント設定 | 等幅フォントとサイズを表示メニューから選択(既定 11pt) |
| 📑 | 折りたたみサイドバー | Ctrl+Shift+B でアイコンだけの細い表示に切り替え、小さな画面でも端末を広く使える |
| 📤 | 書き出し・読み込み | 接続先をパスワード付きファイルにまとめて、別の PC へ移せる |

---

## 💻 動作環境

- Windows 11(.NET Framework 4.8 は Windows 11 に標準で入っています)
- 接続先: OpenSSH などの SSH-2 サーバー(パスワード認証)

---

## 🚀 はじめかた

1. [Releases](https://github.com/onboard-dev/remo/releases) から最新の `Remo_vX.Y.Z.exe` をダウンロードします。
2. 好きなフォルダに置いてダブルクリックで起動します。
   - 初回は「Windows によって PC が保護されました」と表示されることがあります。これは署名の無いアプリに出る表示です。「詳細情報」→「実行」で起動できます。
3. 左の「➕ 接続先を追加」から接続先を登録します。

### 接続先の登録項目

| 項目 | 例 |
|---|---|
| サイト名 | `自宅サーバー` |
| 接続先 | `192.0.2.10`(ポートを変える場合は `192.0.2.10:2222`) |
| ユーザー名 | `user` |
| パスワード | (暗号化して保存されます) |
| 文字コード | UTF-8 / シフトJIS |
| アイコン | 16 種類の絵文字から選択 |

## 🖐️ 使い方

### 接続・切断
- 接続先カードをクリック → 接続。接続中はカードが緑の枠になり、ボタンが「切断」に変わります。
- もう一度クリック → 切断。
- 別の接続先をクリックすると、確認のあと切り替えます。
- カードの「編集」ボタン、または右クリックメニューで編集・複製・削除ができます。

### マウス操作

| 操作 | 動作 |
|---|---|
| ドラッグ | 文字を選択 |
| ダブルクリック | 単語を選択 |
| トリプルクリック | 記憶したウィンドウサイズに戻す |
| 右クリック(選択あり) | 選択した文字をコピー |
| 右クリック(選択なし) | クリップボードの内容を貼り付け |
| ホイール | 過去の出力をスクロール(全画面アプリでは上下キーとして送信) |
| Ctrl+ホイール | 文字サイズの変更 |

### キーボードショートカット

| キー | 動作 |
|---|---|
| Ctrl+Shift+B | サイドバーの開閉 |
| Ctrl+Shift+C / Ctrl+Shift+V | コピー / 貼り付け |
| Shift+Insert | 貼り付け |
| Shift+PageUp / PageDown | 過去の出力をスクロール |

> Ctrl+C・Ctrl+H・Ctrl+B などはターミナル側(シェルや tmux)で使われるため、Remo では横取りしません。

### メニュー

- **接続先**: 追加 / 編集 / 削除 / 書き出し / 読み込み / 切断 / 終了
- **表示**: サイドバーを表示 / 現在のウィンドウサイズを記憶 / フォント / フォントサイズ / 文字コード
- **ヘルプ**: Remo について(バージョン・ライセンス表示)

## 🔐 セキュリティについて

- **接続情報の保存**: `%APPDATA%\Remo\remo.dat` に、Windows の DPAPI(ユーザー単位)で暗号化して保存します。同じ PC・同じ Windows ユーザーでのみ復号できます。
- **ホスト鍵の確認**: 初回接続時にサーバーのホスト鍵を記録し、次回以降に鍵が変わっていた場合は警告します(なりすまし対策)。
- **書き出しファイル(.remo)**: 書き出し時に決めたパスワードから鍵を作り(PBKDF2)、AES-256 で暗号化します。改ざんは HMAC-SHA256 で検出します。パスワードを忘れると開けません。
- **対応している SSH 方式**
  - 鍵交換: curve25519-sha256 / diffie-hellman-group14-sha256 / group14-sha1
  - ホスト鍵: ssh-ed25519 / ecdsa-sha2-nistp256 / rsa-sha2-512 / rsa-sha2-256 / ssh-rsa
  - 暗号: aes256-ctr / aes192-ctr / aes128-ctr
  - MAC: hmac-sha2-256(-etm) / hmac-sha2-512(-etm) / hmac-sha1
  - 認証: パスワード / keyboard-interactive

---

## ⚠️ 制限事項

- 公開鍵認証、ポートフォワーディング、ファイル転送(SFTP/SCP)には対応していません。
- 1 つのウィンドウで同時に接続できるのは 1 台です。
- 暗号方式が AES-GCM / ChaCha20 だけに制限されたサーバーには接続できません。

## 🛠️ ソースからビルドする

追加のソフトは不要です。Windows に標準で入っている C# コンパイラを使います。

```
src\build.bat     … そのままビルド(src\Remo.exe ができます)
src\release.bat   … バージョン番号を入力してビルド
                     (Enter だけなら最後の番号が 1 つ上がります)
                     → Remo.exe と releases\Remo_vX.Y.Z.exe を作成
```

### ソース構成

| ファイル | 内容 |
|---|---|
| `src/Ssh.cs` | SSH-2 プロトコル(鍵交換・暗号化・認証・チャンネル) |
| `src/Crypto25519.cs` | X25519 / Ed25519 の実装 |
| `src/Term.cs` | ターミナルエミュレータ(VT100/xterm 互換、UTF-8/シフトJIS) |
| `src/TermView.cs` | 端末画面の描画・キー入力・マウス操作 |
| `src/Native.cs` | Windows API 呼び出し、DirectWrite によるカラー絵文字描画 |
| `src/UI.cs` | テーマ、接続先リスト、各種ダイアログ |
| `src/MainForm.cs` | メイン画面・メニュー・接続管理 |
| `src/Store.cs` | 設定の暗号化保存、書き出し・読み込み |

## 📦 リポジトリ管理用のバッチファイル

| ファイル | 内容 |
|---|---|
| `git-push.bat` | 個人情報チェックをしてからコミット&プッシュ |
| `git-release.bat` | タグを作成し、GitHub Releases に exe を登録(GitHub CLI を使用) |
| `privacy-patterns.txt` | コミット前にチェックする文字列(プライベート IP、メールアドレスなど) |
| `private-words.txt` | 自分専用の禁止語句リスト(**リポジトリには含まれません**) |

`git-push.bat` は次の場合にコミットを中止します。

- exe・ログ・接続先データ・書き出しファイル(.remo)が含まれている
- プライベート IP アドレス、メールアドレス、ユーザーフォルダのパス、秘密鍵などが含まれている
- `private-words.txt` に書いた語句(ユーザー名など)が含まれている

コミット者のメールアドレスには GitHub の noreply アドレスを使うため、個人のメールアドレスは履歴に残りません。
